# Release Notes — v1.1.0

Оновлення модулю розрахунку замовлень (`billing.js`) у порівнянні з версією `v1.0.0`.

## Added
- Додано спеціальну базову ставку доставки `80.0` для міста `"Kyiv"`.
- Додано явний параметр ставки податку `taxRate` (зі значенням за замовчуванням `0.20`) до функції розрахунку стандартного рахунку.

## Changed
- Коефіцієнт вартості доставки за кілограм ваги збільшено з `12.0` до `15.0`.
- Виконано архітектурний рефакторинг: здійснено перехід від Common, Stamp та Control Coupling до еталонного Data Coupling.

## Breaking Changes
- Змінено сигнатури функцій: `calculateDeliveryCost` тепер приймає примітивні параметри `(city, weightKg)` замість об'єкта `customerProfile`.
- Видалено глобальну змінну `GLOBAL_TAX_RATE`.
- Видалено функцію `processInvoice` та прапорець керування `modeFlag`; замість них впроваджено дві окремі функції: `processStandardInvoice` та `processTaxExemptInvoice`.
